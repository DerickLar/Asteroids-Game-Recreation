## Asteroids-Game-Recreation
![Asteroids_Menu](https://github.com/user-attachments/assets/1ed81f46-32f8-483b-a701-d046e08e2d1c)<br />
A recreation of the classic game Asteroids using the Greenfoot program<br/>
With randomly generated levels that scale in diffuclty as the game goes on <br />
As well as new power ups that the player may pickup to help them beat each level <br />
